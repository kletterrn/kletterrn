AI / FULL-STACK WEB APPLICATION

Better Schooling↗

Eine Note zeigt das Ergebnis.
Aber noch nicht die Ursache.

Eine KI-gestützte Bildungsplattform, die Lehrkräften hilft, grundlegende Lernlücken zu erkennen und passende Unterrichtsmaterialien zu erstellen.

Next.jsTypeScriptFastAPIPythonOpenAI API
Projekt auf GitHub ansehen ↗
Unter der OberflächeTechnik, Entscheidungen & Lernprozess ＋

Was die Anwendung kann

CSV-Import für Leistungsdaten, KI-gestützte Diagnosen, editierbare Lehrmaterialien, PDF-Export und Team-Chat in Echtzeit. Ein deterministischer Demo-Modus funktioniert ohne API-Schlüssel.

Wie sie aufgebaut ist

React und Next.js im Frontend, FastAPI im Backend. SQLAlchemy und SQLite speichern die Daten, WebSockets verbinden Lehrkräfte. Pydantic validiert strukturierte KI-Ausgaben vor dem Speichern.

Transparent entwickelt

Mit Unterstützung von Codex und GPT-5.6 bei Umsetzung, Tests und Fehlersuche. Projektidee, Lehrkräfte-Workflow und Gestaltungsentscheidungen stammen von mir. Der Einsatz von KI ist im Repository dokumentiert.
